# kovalapps-website

Official website for Koval Apps and the Catholic Wallpaper Android application.

## Catholic Wallpaper

Catholic Wallpaper is an Android app that provides daily Catholic Bible verse wallpapers with devotional imagery, sharing, notifications, spoken verse support, and automatic wallpaper updates.

## Features

- Daily Catholic Bible verse wallpapers
- Devotional artwork
- Automatic wallpaper updates
- Home Screen and Lock Screen support
- Save and share wallpapers
- Daily verse notifications
- Text-to-speech verse reading
- Privacy-focused design

## Built With

- HTML
- CSS
- GitHub
- Cloudflare Pages

## App Technology

The Catholic Wallpaper app was built using:

- Kotlin
- Android SDK
- AWS Lambda
- API Gateway
- DynamoDB
- Amazon S3
- Terraform
- Docker
- GitHub Actions CI/CD
